# Portfolio Website

This is a simple and modern portfolio website built with HTML and CSS. It features a homepage with a profile section, a projects section, and a contact section. The design is visually appealing and responsive.

## Features
- Profile section
- Projects showcase
- Contact information
- Responsive design

## Getting Started
Simply open `index.html` in your browser to view the site.

## Customization
Replace the placeholder content in `index.html` and `style.css` with your own information and styles as needed.
